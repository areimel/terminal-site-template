## Highlights

- **Theme registry**: five terminal palettes (green, amber, red, yellow, blue) driven by CSS variables, switchable at runtime and persisted across visits.
- **Effects controls**: boot sequence, noise, scanline, CRT overlay and decoder text, each independently toggleable and fully disabled under reduced motion.
- **Component kit**: a themed set of core primitives (Panel, Button, Heading, Prompt, Divider, Badge, Kbd, Icon, Container) plus content, media, forms, feedback, data, navigation and page-section components — around 60 components across 10 groups, all built on the same tokens, each with a live demo on `/components`.
- **Shell**: a `terminal-shell` custom element with built-in commands (`help`, `ls`, `cd`, `theme`, `effects`, and more), inline and full-screen modes, backed by a testable, DOM-free command engine.
- **Docs**: this site - a docs collection with a file-tree sidebar, an on-page table of contents, and prev/next navigation.
- **Dashboard demo**: an `/app` page showing the data components (stat readouts, meters, tables, log stream) working together.

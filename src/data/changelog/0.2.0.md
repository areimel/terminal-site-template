## Highlights

- **ARDA Terminal Framework rebrand**: the project is now ARDA Terminal Framework (formerly Terminal Site Template). The placeholder organization MAINFRAME-7 is now ARDA, and the placeholder persona Ada Operator is now Field Agent (`agent`), with the shell prompt `guest@arda:~$`.
- **Global content folder**: drop YAML files in `src/data/global-content/`, and they're auto-loaded and exposed from `astrowind:config` as `GLOBAL_CONTENT`, keyed by camelCased filename. Restart the dev server after adding a file.
- **Branding in one file**: `branding.yaml` drives project name, description, company name, persona name/handle, and shell host, exported as `BRANDING` and wired to site title templates, meta description, Open Graph tags, and shell prompt. Explicit values in `src/config.yaml` still override.
- **Typed config exports**: `astrowind:config` exports (`SITE`, `METADATA`, `TEMPLATE`, `GLOBAL_CONTENT` and the rest) now carry their real types. They previously resolved as `any`, so `astro check` can now catch mistakes that used to slip through.

## Upgrading

If you customized the site name, company name, or persona in `src/config.yaml`, those values still work — values in `src/config.yaml` override the defaults from `branding.yaml`. For a fresh fork, edit `src/data/global-content/branding.yaml` to set your project identity, then add persona role/tagline/location to `src/config.yaml`'s `template.identity`.
